# ЛР1: МНК/Ridge на синтетических обращениях

[Назад к общему описанию](../README.md) · [Основной ноутбук](notebooks/regression.ipynb)

Назначенный **вариант 3**, режим **full**. Задача — предсказать `resolution_minutes` по сведениям, доступным при регистрации обращения.

## Данные и протокол

Данные сгенерированы для курса; реальных пользователей и логов компаний нет. Из 1920 размеченных обращений фиксированно выделены **1440 train** и **480 validation**. Отдельные **480 test** не содержат target. `ticket_id` нужен для сопоставления и исключён из входов.

Используются длина сообщения, очередь, возраст аккаунта, число вложений, число операторов, выходной день, размер запроса, канал и тема. Медианы, масштабы и кодирование категорий оцениваются на обучающей части; в CV предобработка заново обучается внутри каждого фолда. Состав и ограничения описаны в [DATA_CARD.md](data/DATA_CARD.md). Паспорт курса также упоминает файлы других занятий, которые не нужны для этой работы и не входят в данную папку.

## Реализованные компоненты

- `ridge_value_gradient`: критерий MSE + lambda * ||w||² и градиент; свободный член без штрафа.
- `solve_ridge`: МНК при lambda=0; Ridge через расширение матрицы строками sqrt(n*lambda)*P и вызов `np.linalg.lstsq`. Обращение матрицы не используется.
- Содержательные выводы о выборе регуляризации, качестве и остатках.

**Предоставлено курсом:** `course_support.py`, загрузка, предобработка, метрики, графики, sklearn-обёртка `OwnRidge`, процедуры CV и проверки. Собственный QR/SVD и ручная CV-процедура варианта 4 не реализуются в назначенном варианте 3. Использование ИИ раскрыто в ноутбуке.

Проверки частей A/B включают известное решение, зависимые столбцы, конечные разности, сравнение с sklearn Ridge при alpha=n_fit*lambda, сдвиг target и сохранность входных массивов.

## Эксперимент и результат

Три фолда `KFold(shuffle=True, random_state=23)` строятся только внутри train. Признаки и предобработка зафиксированы; меняется только lambda. Выбор — минимум средней MSE по фолдам.

| lambda | CV MSE, мин² |
|---:|---:|
| 0 | 341.508 |
| 0.03 | 351.130 |
| 1 | 943.037 |

Выбрана **lambda=0**: гипотеза о преимуществе небольшой регуляризации 0.03 в этом опыте не подтвердилась.

После обучения на полном train:

| Модель | Validation RMSE, мин | Validation MAE, мин |
|---|---:|---:|
| Реализованный решатель, lambda=0 | 14.734 | 10.826 |
| Постоянный прогноз среднего train | 49.920 | 40.881 |

Validation MSE выбранной модели — **217.103 мин²**. При больших очередях в остатках сохраняется структура: линейное представление не полностью описывает зависимость. Корректность решателя и пригодность модели для новых данных — разные вопросы.

## Ограничения

Validation просматривалась в ходе работы и не является независимым финальным тестом. Выбранная CV-оценка тоже использована для выбора lambda. Ответов test нет, поэтому его качество неизвестно. Синтетические зависимости и случайное разбиение не описывают автоматически реальные обращения во времени.

Старый `submissions/lab1_v3_predictions.csv` исключён: при `EXPORT_FINAL=False` его создание текущим запуском не подтверждается. Условный экспорт оставлен в ноутбуке и по умолчанию выключен.

## Файлы и запуск

```bash
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m jupyter lab notebooks/regression.ipynb
```
