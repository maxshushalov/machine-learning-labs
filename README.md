# Машинное обучение: регрессия и классификация

Здесь собраны две мои лабораторные по машинному обучению. В первой работе я реализовал МНК и Ridge и сравнил несколько значений регуляризации. Во второй разбирался с классификацией: логистической регрессией, деревьями, ансамблями, SVM и softmax.

Автор: Максим Чучкалов, группа Б24-507.

## Лабораторные работы

### 1. МНК и Ridge

Задача первой работы — предсказать время решения обращения в поддержку. Данные синтетические: 1440 обращений для обучения, 480 для validation и ещё 480 для test без ответов. Выполнен вариант 3 в режиме `full`.

Я реализовал функцию MSE с L2-регуляризацией, её градиент и решение через `np.linalg.lstsq`. Для Ridge используется расширенная матрица, свободный член не штрафуется. В ноутбуке есть проверки градиента конечными разностями и сравнение с `sklearn`.

Значения λ = 0, 0.03 и 1 сравнивались по трём фолдам внутри train. Наименьшая средняя MSE получилась при λ = 0: 341.508. Небольшая регуляризация в этом эксперименте результат не улучшила.

На validation модель получила RMSE 14.734 минуты и MAE 10.826 минуты. Для сравнения, постоянный прогноз среднего по train дал RMSE 49.920 и MAE 40.881 минуты.

[Описание работы](regression/README.md) · [Ноутбук](regression/notebooks/regression.ipynb)

### 2. Классификация, ансамбли и SVM

Во второй работе выполнен вариант 2. Для бинарной классификации используется Raisin, для многоклассовой — Dry Bean.

В заданиях я реализовал logistic loss и градиент, критерий неоднородности и поиск разбиения дерева, формирование выборок для ансамбля, объединение прогнозов и расчёт OOB. Также реализовал разложение Brier, функции потерь и градиент для SVM, правила остановки, RBF-ядро и компоненты softmax.

Настройки ансамбля выбирались по Brier на validation, а gamma для RBF — по validation accuracy. После выбора модели оценивались на test.

Результаты на Raisin, test из 180 объектов:

| Модель | Accuracy | Brier |
|---|---:|---:|
| Логистическая регрессия | 0.866667 | 0.093543 |
| Дерево | 0.894444 | 0.091897 |
| Ансамбль | 0.877778 | 0.088633 |
| SVM, squared hinge | 0.872222 | — |
| SVM, Huber hinge | 0.866667 | — |
| RBF SVC | 0.872222 | — |

У дерева оказалась самая высокая accuracy, а у ансамбля — наименьший Brier среди моделей с рассчитанными вероятностями. Для SVM в этой работе использовались scores и классы, поэтому Brier для них не указан.

На Dry Bean softmax получил test accuracy 0.904762 и log-loss 0.373756. Это отдельная задача с семью классами, поэтому её accuracy нельзя напрямую сравнивать с результатами на Raisin.

## Что стоит учитывать в результатах

В первой работе validation использовалась при разработке, а ответы test недоступны. По этим результатам нельзя судить о качестве на реальных обращениях.

Во второй работе использовано одно фиксированное разбиение данных. На другом разбиении порядок моделей по качеству может измениться. Обучение softmax завершилось после 2500 обновлений по лимиту итераций; норма градиента осталась около 0.001254.

## Запуск

Используются Python 3.12, NumPy, pandas, SciPy, scikit-learn, Matplotlib и Jupyter.

Из корня репозитория на macOS или Linux:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-lock.txt
python -m jupyter lab
```

В Jupyter откройте нужный ноутбук:

- `regression/notebooks/regression.ipynb`
- `classification/classification.ipynb`

Выберите ядро созданного окружения и выполните `Restart Kernel → Run All`. Данные уже лежат в репозитории, скачивать их отдельно не нужно. В ноутбуках сохранены таблицы и графики, поэтому результаты можно посмотреть и без запуска.
