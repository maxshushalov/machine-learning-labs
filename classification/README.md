# ЛР2: классификация, ансамбли, SVM и softmax

[Назад к общему описанию](../README.md) · [Основной ноутбук](classification.ipynb)

Назначенный **вариант 2**: общие задания по бинарной классификации и многоклассовое дополнение softmax.

## Данные и схема эксперимента

- **Raisin:** 900 объектов, 7 морфологических признаков, два класса (`Kecimen=0`, `Besni=1`). Train/validation/test: **540/180/180**.
- **Dry Bean:** исходный CSV содержит 13 611 объектов, 16 признаков, 7 классов. После удаления полных дубликатов выбирается стратифицированная подвыборка **2100** объектов; split **1260/420/420**.

CSV сохранены полностью; фильтрация и подвыборка выполняются в памяти. Разбиения стратифицированы, seed=17. `StandardScaler.fit` использует только train; дерево и ансамбль получают исходные признаки, линейные модели — стандартизованные. [Источники, DOI, лицензии и SHA-256](DATA_SOURCES.md).

## Что реализовано в заданиях

- Устойчивая logistic loss и градиент: `logaddexp`, сигмоида с разделением по знаку.
- Неоднородность `sqrt` и поиск `best_split` перебором порогов, O(d*n²) в узле — допустимый путь варианта 2; правила ничьих и минимального листа.
- Планы bootstrap/subsampling с кратностями, организация обучения ансамбля через предоставленный адаптер, прогнозы участников и soft/hard-агрегация.
- Взвешенное Brier-разложение, его математическое обоснование и OOB-аккумуляторы для префиксов ансамбля.
- Squared hinge и Huber hinge, цель SVM и градиент, правила остановки и подключение к готовому градиентному спуску.
- RBF-ядро и score по опорным объектам модели готового `SVC`.
- Устойчивый softmax/log-sum-exp, многоклассовая цель и градиенты.

**Предоставлено курсом:** загрузчики, оптимизатор `provided_gd`, рекурсия и обход дерева, адаптер `DecisionTreeClassifier`, готовое обучение `SVC`, часть проверок, экспериментов и визуализаций. Ансамбль использует адаптер деревьев с Gini; он не строится на собственном `best_split`. Использование ИИ для объяснений, кода и интерпретации раскрыто в ноутбуке.

Неактивные дополнительные задания по шуму с TODO относятся к вариантам 1/3 и не входят в вариант 2. Их шаблон сохранён и явно обозначен.

## Выбор настроек

Для ансамбля сравниваются выборки с возвращением и без возвращения при доле строк 0.6, всех семи признаках и префиксах B=1,4,16,64. Минимум validation Brier выбирает **64 дерева с возвращением**: Brier **0.096033**, против 0.097474 без возвращения при B=64. OOB Brier выбранного ансамбля — **0.113087**, покрытие **540/540**.

Для RBF проверяются gamma=0.01,0.1,1,10 при C=1. По validation accuracy выбрана **gamma=0.1**: **0.888889**. При равенстве предусмотрено меньшее gamma. Финальная test-ячейка следует после выбора настроек. Проверяемый путь не использует test для подбора; историю прежних ручных экспериментов восстановить нельзя.

## Итог на test

**Raisin, одна бинарная задача, 180 объектов:**

| Модель | Accuracy | Brier |
|---|---:|---:|
| Логистическая регрессия | 0.866667 | 0.093543 |
| Дерево с собственным разбиением | 0.894444 | 0.091897 |
| Выбранный ансамбль | 0.877778 | 0.088633 |
| SVM, squared hinge | 0.872222 | — |
| SVM, Huber hinge | 0.866667 | — |
| RBF SVC, gamma=0.1 | 0.872222 | — |

Дерево дало наибольшую test accuracy среди этих моделей; ансамбль — наименьший Brier среди моделей с рассчитанными вероятностями. Порядок по accuracy изменился относительно validation. У SVM здесь рассчитаны scores и классы; вероятности для Brier не подготовлены.

**Dry Bean, отдельная многоклассовая задача, 420 объектов:** свой softmax дал accuracy **0.904762**, log-loss **0.373756**, Brier_K **0.089854**. В работе Brier_K = 0.5 * mean(sum((p-one_hot(y))²)); при двух классах это обычная бинарная Brier score.

На validation softmax получил accuracy **0.923810**; обучение остановилось по `max_iter` после **2500** обновлений, норма градиента **0.001254**. Это ограничение оптимизации, а не подтверждение точного оптимума.

## Ограничения и воспроизведение

Одно разбиение и один seed ограничивают устойчивость выводов. Brier-разложение не гарантирует превосходство ансамбля над лучшим деревом по accuracy. При малых B меняется состав объектов с OOB-прогнозом. Для вероятностного сравнения SVM потребовалась бы отдельная калибровка без подбора по test. Метрики Raisin и Dry Bean нельзя использовать как общий рейтинг моделей.
